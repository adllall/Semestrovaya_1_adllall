# Респонс — каталог коллекционных карточек

Семестровая работа №1, Мельникова Аделина 11-507.

В галерее 40 карточек. Их можно искать по названию, сортировать и фильтровать по типу. У каждой карточки есть своя страница с описанием. После регистрации можно сохранять карточки в избранное и писать к ним заметки. В админке можно добавлять, редактировать и удалять карточки и категории.

## Как запустить через Docker

Запустите Docker Desktop и откройте PowerShell в папке проекта. Если файла `.env` ещё нет, скопируйте шаблон.

```powershell
Copy-Item .env.example .env
```

В `.env` заполните `POSTGRES_PASSWORD` и `ADMIN_PASSWORD`. Придумайте для них разные пароли. Пароль администратора должен содержать от 10 до 128 символов. Затем запустите проект.

```powershell
docker compose up --build -d
```

При первом запуске PostgreSQL загрузит карточки, а приложение создаст администратора. Логин по умолчанию — `admin`, начальный пароль берётся из `ADMIN_PASSWORD`. Откройте [галерею](http://localhost:8080/) или [страницу входа](http://localhost:8080/login).

Чтобы остановить проект, выполните `docker compose down`. Карточки, аккаунты и заметки сохранятся. Если порт `8080` занят, поменяйте `APP_PORT` в `.env` и откройте сайт на новом порту. Если сайт не открылся, проверьте сообщения через `docker compose logs app`.

## Как запустить без Docker

Понадобятся .NET SDK 9 и PostgreSQL. Команды ниже создают базу `response_game` и загружают в неё карточки. Если база уже есть, пропустите `createdb`. Для обновления схемы достаточно `01-schema.sql`, а `02-catalog.sql` нужен для начального заполнения.

```powershell
createdb -h localhost -U postgres response_game
psql -h localhost -U postgres -d response_game -v ON_ERROR_STOP=1 -f database/01-schema.sql
psql -h localhost -U postgres -d response_game -v ON_ERROR_STOP=1 -f database/02-catalog.sql
```

Перед запуском укажите пароль PostgreSQL и пароль для создания администратора в переменных окружения.

```powershell
$env:POSTGRES_PASSWORD = "ваш пароль PostgreSQL"
$env:ADMIN_PASSWORD = "ваш пароль для админки"
dotnet run --project Semestrovaya/Semestrovaya.csproj
```

Приложение по умолчанию подключается к `localhost:5432` под пользователем `postgres` и открывает сайт на `http://localhost:8080/`. Для другого адреса сайта задайте `HTTP_PREFIX`. Параметры подключения к базе можно поменять через `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB` и `POSTGRES_USER`.

## Что попробовать на сайте

- Найдите карточку в галерее и откройте её страницу. Кнопка «Обновить» подтягивает свежие данные без перезагрузки.
- Зарегистрируйтесь, добавьте карточку в избранное и сохраните заметку.
- Войдите как администратор и создайте категорию и карточку. Для проверки можно взять изображение `/images/Avel.jpg`. В описании можно выделить текст полужирным или курсивом.

## Как устроен проект

Сервер написан на C# и .NET 9 с использованием `HttpListener`. Маршрутизация, MVC, шаблонизатор и ORM реализованы в проекте. Для базы используется PostgreSQL, а для страниц — обычные HTML, CSS и JavaScript.

Код приложения лежит в `Semestrovaya`, тесты — в `Semestrovaya.Tests`, SQL-скрипты — в `database`.

## Тесты

```sh
dotnet test Semestrovaya.sln
```

Для интеграционного теста ORM укажите в `SEMESTROVAYA_TEST_POSTGRES` строку подключения к отдельной тестовой базе. Пользователю базы нужно право создавать схемы. Тест сам создаст временную схему и удалит её после проверки.
